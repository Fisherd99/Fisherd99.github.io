# 口琴曲库源文件

这里存放**手写的简谱文本源**，是曲库的权威来源。构建脚本把它们转换成 MusicXML 供网页播放器使用。

```
public/scores/<slug>/score.txt ← 你手写，入库
        ↓  node scripts/generate-scores.js
public/scores/<slug>/score.musicxml ← 生成物，入库，供播放器与下载
public/scores/<slug>/score.json     ← 生成物，入库，供简谱显示
```

`<slug>` 用英文 kebab-case，与文章路径保持一致（例如 `tabi-no-tochu`）。

## 目录

| 命令 | 作用 |
| --- | --- |
| `npm run generate-scores` | 生成 MusicXML |
| `node scripts/generate-scores.js --verify` | 生成后额外用 alphaTab 读回校验 |

`docs:dev` / `docs:build` 已把生成步骤串在前面，通常不必手动运行。**任何解析、拍数或音域错误都会让构建失败** —— 这是刻意的，报错比悄悄补休止诚实。

## 文件格式

头部以 `---` 结束，之后是正文。

```
title: 旅の途中
subtitle: [A]
tempo: 75         // 每分钟四分音符数，会写进 MusicXML，决定播放器速度
time: 6/8
key: 4            // MusicXML 的 fifths：0=C 大调，4=E 大调，-1=F 大调
program: 23       // GM 音色号，23 = Harmonica
divisions: 8      // 四分音符的时值单位。8 表示十六分=2、三十二分=1
---

#1__ #2__ #3_ #1_ ,#5_ ,7- | #1 #5_ #4_ #1 #2_ 3_ |
```

### 音高

| 写法 | 含义 |
| --- | --- |
| `1` – `7` | 级数（1=C 时即 C D E F G A B） |
| `0` | 休止符 |
| `#n` | 升高半音。等于半音阶口琴按下按键：`#1` = C#、`#3` = F、`#7` = C（跨到下一个八度的 1） |
| `bn` | 降低半音 |

基准 **`1` = C5（MIDI 72）**。12 孔半音阶口琴的音域是 C4–C7，即 `,1` 到 `''1`，超出的音会报错。

### 八度（写在音符**左边**，可叠加）

| 写法 | 含义 |
| --- | --- |
| `,1` | 低八度 |
| `,,1` | 低两个八度 |
| `'1` | 高八度 |
| `''1` | 高两个八度 |

八度在左、时值在右，两个维度各占一侧，一个 token 从左往右读就是「八度 → 音级 → 时值」，没有歧义。

### 时值（写在音符**右边**）

默认是**四分音符**。

| 写法 | 时值 |
| --- | --- |
| `1` | 1 拍（四分） |
| `1-` | 2 拍（二分）—— 每根 `-` **加一拍** |
| `1--` | 3 拍（附点二分，简谱里惯用这种写法而不是加附点） |
| `1---` | 4 拍（全音符） |
| `1_` | 半拍（八分）—— 每根 `_` **减半** |
| `1__` | 四分之一拍（十六分） |
| `1___` | 八分之一拍（三十二分，需要 `divisions: 8` 或更高） |
| `1.` | 附点，时值 ×1.5（附点四分 = 1.5 拍） |
| `1-~ 1_` | 2.5 个四分音符时值（二分 + 八分，用延音线连接） |
| `1_.` | 附点八分 |
| `1__.` | 附点十六分 |
| `1~` | 连音线，连到后一个同音高的音 |

时值必须能落在 `divisions` 网格上：`divisions: 4` 只到十六分，要用三十二分就得设 `divisions: 8`。

### 结构

| 写法 | 含义 |
| --- | --- |
| `\|` 或 `\|\|` | 小节线（两者目前等价，必须满一小节） |
| `\|:` | 反复开始 |
| `:\|` | 反复结束 |
| `:\| xN` | 反复 N 遍，**N 可以是任意正整数**（省略则默认 2） |
| `\|1.` `\|2.` | 第一/第二结尾（`\|1.` 自带小节线，该结尾延伸到 `:\|` 或下一个结尾） |
| `[A]` | 段落标记（单独一行），显示在简谱上方 |
| **换行** | **乐句行**，纯显示用，可以在小节中间断 |
| `\t` | 行内制表：后面的音符移到下一制表位，用留白区分同一行内的乐句；连续使用可跨多个制表位 |
| `= 歌词` | 行内第一个 `=` 之后为该乐句的歌词，显示在简谱上方 |

**小节和乐句是两个层次**：小节是时间的单位（必须服从拍号），乐句是意义的单位（按你练习时想要的断句）。旋律常常从弱起进入、并不落在小节线上，所以两者本来就不重合 —— 用换行自由划分乐句即可，`|` 仍按实际小节摆放。

例如 `1 2 \t 3 4 |` 将两组音符排在同一行，以制表留白区分。输入的是反斜杠加字母 t（可紧贴音符），不是键盘 Tab；制表位每隔 4 个字号宽度，剩余空间不足时以乐句为单位换行。只有单个乐句超过整行宽度时才在句内折行，避免横向溢出。它不增加休止、不改变时值、五线谱或播放音序；要强制另起一行仍使用换行。

### 注释

`//` 起至行尾。头部和正文都可以用。

> 注意：不能用 `#` 当注释符 —— 它已经是升号标记。

## 已经知道的边界

- **每小节拍数必须与 `time` 完全吻合**，否则报错并指出第几小节差几拍。脚本不会自动切分小节，也不会自动补休止 —— 由你决定怎么改。
- **第一小节允许短于整小节**（弱起 / anacrusis），只对第一小节生效；其余小节一律严格校验。
  但要注意：**播放器会把短的第一小节补满一整小节**，弱起与下一小节之间就会出现空档。
  所以实践中不要用"独立弱起小节"，而是像原谱那样把弱起放在一个整小节内部
  （例如「二分音符 + 八分休止 + 弱起」，正好填满 6/8）。
- **连音线 `~` 支持跨小节和跨段落**，后一个音必须与前一个同音高。
- **时值必须能表示为整数单位**。默认 `divisions: 4` 覆盖全音符到十六分及附点；更细的时值需要调大 `divisions`。
- **反复次数**用 `:| xN` 表达；第一/第二结尾用 `|1.` / `|2.` 表达，播放时间轴由 alphaTab 展开。

## 时值只能靠人定

音高可以从手写谱读出来，**时值读不出来** —— 手写简谱通常只有小节线，没有下划线、附点和延音线。

MuseScore 站点有 Cloudflare 人机校验，脚本抓不到。**但如果你能拿到任意来源的 MusicXML / MIDI 文件**，可以精确解析出每个音符的时值再翻译成本格式。

参考谱只是起点：别人的编配（可能是钢琴版）未必等于你的口琴演奏。**你的视频才是最终依据。**

## 校对方法

生成后的 `.musicxml` 可以直接拖进 [MuseScore Studio](https://musescore.org/) 打开播放。**用耳朵对着视频逐句听** —— 不需要会看五线谱，哪里不对就回改源文件、重新生成。
